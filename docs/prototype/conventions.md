# Project conventions

## External further-reading links (Glyph Sleuth)

Entity pages carry **exactly one** outbound further-reading link, placed at the end of the
page's prose write-up. One line, plain proof-blue link with hairline underline (no badge),
marked visibly as external (`↗` plus "— external"), `target="_blank" rel="noopener"`.

Source priority, first that covers the entity wins:
1. r12a.io script notes (treated as a peer source, not just a pointer)
2. Writing Systems Technical Resources (writingsystems.info)
3. Wikipedia (always-available fallback)

Omniglot is excluded — wrong trust register for this audience.

The label must say what is on the other end and name the source, e.g.
"Orthography and encoding notes for Malayalam at r12a.io ↗", not a generic "learn more".

Same convention on the language page when built, scoped to the language rather than the script.
