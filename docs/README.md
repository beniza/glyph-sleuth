# docs

**No task lists live here.** Open work is on the
[board](https://github.com/users/beniza/projects/10); how to run and work on the
project is in [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

Two files here are live. Everything else is source material, kept because it is
the record of what was asked for and what was decided — none of it describes the
built site, and where it disagrees with the code, the code is right.

## Live

| | |
| --- | --- |
| [`DECISIONS.md`](DECISIONS.md) | Standing rules and why they stand. Revisions are kept, not overwritten. **Read before changing what the build publishes.** |
| [`BRIEF.md`](BRIEF.md) | The original brief. Archival: it describes a plan, and several of its decisions were revisited — see `DECISIONS.md`. |

## Source material, archival

| | |
| --- | --- |
| `chats/chat1.md` | The conversation the project came from. `DECISIONS.md` D2 cites its §10 for the licensing rule, which is why it is kept rather than summarised. |
| `addenda/` | Five settled specs written after the brief: Compare, Identify, the shaping-engine matrix, the desktop companion, community issues. The Compare cards on the board are drawn from `addendum-compare-final.md`. |
| `prototype/` | The current prototype's spec bundle — data shapes, behaviour, conventions, and screenshots of every page. The design the build was checked against. Its own `TODO.md` is the prototype's open items, not this project's. |
| `prototype-v1/` | The earlier prototype, single-file. Superseded, kept for the record. |

The prototype's HTML itself is not here — it is served at `/mockup/` from
`site/mockup/`, so there is one copy rather than two that drift. See
`prototype/WHERE-IS-THE-HTML.md`.

## Retired

`PROGRESS.md`, `TODO.md` and `BUILD-PLAN.md` were removed on 2026-08-20 when the
board became the single source of truth. Nothing was lost: the checklists became
issues, the policies became `DECISIONS.md`, and the measured build cost moved to
`CONTRIBUTING.md`. `HANDOFF.md` was renamed `BRIEF.md` in the same change.
