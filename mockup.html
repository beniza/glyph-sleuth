Coverage is a cliff, not a slope

Across the 209 families installed on the machine this was measured on, Hindi is covered by 2, Amharic by 1, Burmese by 1. There is rarely a middle: a face either has the script or has none of it. Ranking every family against a language makes that visible in a second, and names the exact characters that would drop to fallback.

The language data is SIL's — langtags.json for the 9,600 tags, SLDR for the exemplar characters of each one, fetched on demand and cached.

Every number here was measured

Nothing on this page is filler. The face counts, the block coverage, the per-variant tallies under each asterisk — all of it came from scanning the 401 faces actually installed, using the same index the app runs on.

Property labels come from the regex engine's own tables, so every chip shown is valid inside a real \p{…} you can paste into code. The tests assert that round trip.
